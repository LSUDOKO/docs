# docs

Documentation and Developer resources for Layer5 products

Package manager: npm.

## Commands

- build: `npm run build`
- test: `npm test`
- build: `go build ./...`
- test: `go test ./...`

## Layout

- `archive/`
- `assets/`
- `charts/`
- `content/`
- `data/`
- `i18n/`
- `layouts/`
- `static/`

## Rules

- Run `npm test` before you say a change is done.
- Never commit secrets or `.env` files.
